## Problem Statement

회의 시간이 길어질수록 실제 비용이 얼마나 드는지 시각적으로 보여주는 웹앱.
택시 미터기처럼 돈이 올라가는 불안감을 핵심 감정으로 활용.
GitHub 포트폴리오용 데모 프로젝트.

## What Makes This Cool

1. **택시 미터기 감정** — 돈이 실시간으로 올라가는 걸 보는 시각적 긴장감
2. **오도미터 숫자 애니메이션** — 숫자가 기계적으로 돌아가는 물리적 느낌
3. **감정 단계** — 시간에 따라 배경색이 초록→노랑→빨강으로 변하는 택시미터 UX
4. **재미있는 비교** — "이 회의 비용으로 피자 42판 살 수 있었습니다" 같은 유머
5. **히스토리 + 통계** — 지난 회의들 비용 추적, 간단한 스파크라인

## Constraints

- 바닐라 JS + CSS + localStorage only (프레임워크/빌드도구 없음)
- file:// 프로토콜 호환 (로컬에서 바로 열기)
- 외부 CDN 의존성 없음 (Odometer.js는 벤더링)
- XSS 방지: textContent only, innerHTML 사용 금지
- FR ~28개, NFR 포함 medium 복잡도
- 통화: 원(₩) 기본, 설정에서 변경 가능 (₩/$/€)
- 접근성: 포트폴리오 데모 목적으로 out of scope (WCAG 미적용)
- JS 모듈 로딩: IIFE 패턴 + 단일 전역 객체 (MeetingCost), script 태그 순서 명시
- Odometer.js: file:// 호환 검증 후 사용, 실패 시 CSS-only 대체 구현

## Premises

1. 바닐라 JS + localStorage로 FR 28개 규모를 깔끔하게 관리할 수 있다.
2. file:// 호환이 우선, GitHub Pages 배포는 보너스.
3. 핵심 가치는 "시각적 재미" — 정확한 시급 계산보다 애니메이션, 색상 변화, 비교가 더 중요.
4. 히스토리+통계는 차트 라이브러리 없이 CSS/Canvas로 처리.

## Approaches Considered

### Approach A: Minimal Viable
타이머+돈카운터+색상변화+비교. 히스토리 최소.
Effort: S (FR ~20개). Completeness: 5/10.
Pros: 빠름. Cons: 통계/리더보드 없음, 포트폴리오로 약함.

### Approach B: Full Experience (CHOSEN)
오도미터+택시미터 색상+재미비교+히스토리+간단통계+다크모드.
Effort: M (FR ~28개). Completeness: 8/10.
Pros: 포트폴리오 충분, 적정 복잡도. Cons: A보다 시간 더 걸림.

### Approach C: Showpiece
B + 리더보드(wall-of-shame) + 스크린샷 카드 내보내기 + 소리효과.
Effort: L (FR ~35개). Completeness: 10/10.
Pros: 가장 인상적. Cons: 워크플로우 테스트에 과함.

## Recommended Approach

**Approach B: Full Experience**

핵심 모듈:
1. **Timer Engine** — 시작/일시정지/정지/리셋, requestAnimationFrame 기반
2. **Cost Calculator** — 참석자 수 × 시급 × 경과시간, 실시간 업데이트
3. **Odometer Display** — Odometer.js 벤더링, 숫자 스피닝 애니메이션
4. **Emotion Stage** — 시간 임계값(고정값)에 따른 배경색/이모지/메시지 변화
   - 0~15분: 초록 #4CAF50 (평온) "순조롭습니다"
   - 15~30분: 노랑 #FFC107 (주의) "슬슬 길어지네요"
   - 30~60분: 주황 #FF9800 (경고) "이쯤이면..."
   - 60분+: 빨강 #F44336 (위험) "회의의 늪"
   - 임계값은 고정 (사용자 설정 불가, 복잡도 통제)
5. **Fun Comparisons** — 비용이 비교 항목의 가격을 넘을 때마다 새 항목이 슬라이드인으로 등장
   - 하드코딩된 15~20개 항목 배열 (예: {name: "커피", cost: 5000, emoji: "☕"})
   - 타이머 아래 단일 카드로 표시, 가장 최근 넘긴 항목이 보임
   - 예: "이 회의 비용 = 커피 3잔 ☕"
6. **Settings** — 참석자 수, 평균 시급 설정, localStorage 저장
7. **History** — 완료된 회의 목록, 날짜/시간/비용/참석자 기록
8. **Statistics** — 총 회의 수, 총 비용, 평균 회의 시간, Canvas 스파크라인 (x축: 최근 회의 인덱스, y축: 비용, 정적 표시)
9. **Dark Mode** — CSS 변수 기반 테마 토글
10. **Tab Navigation** — 타이머 / 히스토리 / 통계 탭

## What I noticed about how you think

- "전부 다 넣자"라고 했을 때 — 재미있는 걸 만들 때 타협하지 않는 성향. 포트폴리오라서가 아니라, 만드는 과정 자체를 즐기는 사람.
- 스택 선택에서 "이전과 동일"을 골랐을 때 — 검증된 걸 다시 쓰는 실용성. 새 기술 시도가 목적이 아니라 워크플로우 검증이 목적이라는 걸 명확히 알고 있음.
- 범위를 "중간"으로 잡았을 때 — 테스트 목적에 맞는 적정 복잡도를 스스로 조절할 줄 아는 감각.
